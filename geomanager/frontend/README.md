# GeoManager Frontend Demo

Interactive visual demo for the GeoManager lifecycle principle:
- managed polygons in **EPSG:31370**
- fiscal GRB parcels (Adpf OGC Feature API) as background
- time slider to simulate year-over-year geometry update
- optional coupling with the backend MVP artifacts generated by `geomanager/mvp_lifecycle_demo.py`

## Files
- `index.html`
- `app.js`
- `styles.css`

## Run locally
1. Generate the backend demo artifacts:

```powershell
.\.venv\Scripts\python.exe geomanager\mvp_lifecycle_demo.py
```

This writes:
- `geomanager/mvp_output/runs.json`
- `geomanager/mvp_output/history_summary.json`
- `geomanager/frontend/data/mvp_runs.json`

2. Start a local static server (recommended to avoid browser CORS/file limitations):

```powershell
cd geomanager/frontend
python -m http.server 8080
```

Open:
- `http://localhost:8080`

## How it works
- The app first tries to load `./data/mvp_runs.json` generated by the backend MVP.
- If present, those artifacts drive the lifecycle geometries and decision status shown in the demo.
- If no artifact is present, the app falls back to built-in sample geometries.
- The app discovers available `AdpfYYYY` collections from the Vlaamse OGC Features API.
- It loads parcels for the current map extent from selected year A or B.
- Slider behavior:
  - `0%` = baseline year A geometry
  - `100%` = updated year B geometry
  - intermediate values interpolate between both (visual lifecycle effect)
- Parcel background switches by slider side:
  - `< 50%` uses year A parcels
  - `>= 50%` uses year B parcels

## Notes
- This is a visual simulation to communicate concept and value.
- It does not run BRDR in-browser; it demonstrates lifecycle behavior and reference drift effects.
- For large map extents, parcel loading may be heavy; use the reload button after zooming.
